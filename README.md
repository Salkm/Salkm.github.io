# Saleem KM Portfolio

Static export of the Lovable portfolio originally published at:

https://build-your-best-site-66.lovable.app

## Deploy Options

### GitHub Pages

1. Create a new public GitHub repo, for example `saleem-portfolio`.
2. Push this folder to the repo.
3. In GitHub, open `Settings` -> `Pages`.
4. Set `Source` to `GitHub Actions`.
5. Push to `main`; the included workflow publishes automatically.

### Vercel

1. Import the GitHub repo in Vercel.
2. Framework preset: `Other`.
3. Build command: leave empty.
4. Output directory: `.`.

### Netlify

1. Import the GitHub repo in Netlify.
2. Build command: leave empty.
3. Publish directory: `.`.

## Local Preview

```powershell
npm install
npm run dev
```
